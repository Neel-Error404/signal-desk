# SD-005 Immutable Completed Fix Contract

**Version:** 1

**Status:** Ratified bounded implementation contract

**Change class:** `public-contract`

**Owner:** Neel

**Runtime boundary:** local-only operator-confirmed completion record

## Contract claim

SD-005 lets a local product owner record one immutable Completed Fix for one existing Review
Delivery. It preserves the exact product lineage without claiming that SignalDesk or Elder
performed or independently verified the merge.

## Completed Fix record

| Field | Contract |
|---|---|
| `id` | Server-generated UUID; immutable |
| `reviewDeliveryId` | Required source Review Delivery UUID; immutable and unique |
| `mergedCommitSha` | Lowercase 40- or 64-character hexadecimal Git object identifier; immutable |
| `completionSummary` | 1 to 2,000 Unicode code points; immutable |
| `completedBy` | 1 to 120 Unicode code points; unverified local label; immutable |
| `completedAt` | Server-generated UTC RFC 3339 timestamp; immutable |

## `POST /api/v1/review-deliveries/{reviewDeliveryId}/completed-fix`

Request:

```json
{
  "mergedCommitSha": "0123456789abcdef0123456789abcdef01234567",
  "completionSummary": "The human owner merged the reviewed fix after all required checks passed.",
  "completedBy": "Neel",
  "mergeConfirmedOutsideSignalDesk": true,
  "contentAcknowledged": true
}
```

The request is closed. The merge confirmation and content acknowledgement must both be exactly
`true`. Text is bounded and checked by the deterministic content policy. Success is `201
Created` with `completedFix` and complete Feedback-to-Review Delivery lineage.

## Signal detail compatibility

`GET /api/v1/signals/{signalId}` retains all SD-001 through SD-004 fields and adds
`completedFix: null` or the serialized immutable Completed Fix.

## Errors

| Status | Code | Condition |
|---|---|---|
| 404 | `review_delivery_not_found` | The source Review Delivery does not exist |
| 409 | `completed_fix_exists` | The Review Delivery already has a Completed Fix |
| 422 | `external_merge_confirmation_required` | External human merge was not explicitly confirmed |

Malformed input uses `invalid_request`; storage and content failures retain existing fail-closed
errors.

## Product context registration

`delivery/review-delivery-contract.json` lists `delivery/completed-fix-contract.json` in its
`contextContracts` registry. Consumers must keep the reference inside the project root, require
the same `projectId`, validate the closed lifecycle schema, and treat its authority as
descriptive only.

## Non-claims

SD-005 does not query GitHub, verify or execute a merge, synchronize PR state, deploy, release,
communicate with customers, authenticate users, or grant Elder autonomous authority.
