1. Run from the SignalDesk repository root.
2. Install exact dependencies with `npm ci`.
3. Keep Google Chrome installed at its normal Windows location.
4. Do not set a production `DATABASE_URL` for the test ladder.

`.elder/runtime/` paths. They apply the committed migration and stop their processes on exit.

## Failure Reproduction Notes

The qualification intentionally records failures instead of discarding them:

1. Foundation initially failed because Prisma schema validation had no deterministic validation-only
   URL. `scripts/validate-prisma-schema.mjs` now invokes the local Prisma CLI with a non-connecting
   placeholder.
2. Foundation then failed the React effect rule. Initial loading is now scheduled outside the
   synchronous effect body.
3. The first Windows Prisma wrapper returned no process status. Test launchers now call local Node
   CLIs directly and raise explicit spawn errors.
4. Integration exposed overbroad `P2002` mapping. Only the `Signal.feedbackId` constraint now maps
   to `lineage_conflict`; unrelated uniqueness failures map to `storage_unavailable`.
5. Workflow first failed on an ambiguous accessible selector, then exposed a real missing
   `/favicon.ico` resource. The selector was made role-specific and the favicon route was added.
6. Next.js attempted to append framework instructions to Elder-owned `AGENTS.md`. The change was
   removed and `agentRules: false` prevents recurrence.

No failed level was bypassed. Each failed level was rerun after its root cause was corrected.
