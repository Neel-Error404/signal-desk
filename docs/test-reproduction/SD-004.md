complete source lineage, while the repository-owned delivery contract remains deterministic and
cannot expand Elder authority.

## Workflow correction

The first Workflow run passed desktop and failed mobile because both browser projects submitted
the same globally unique pull-request URL for two different briefs in their shared test database.
PostgreSQL correctly rejected the second record with `review_delivery_exists`. The fixture now
uses a distinct PR number for each browser project. No product uniqueness or error behavior was
weakened; Workflow must be rerun at the same level.
