# SD-005 Verification Plan and Reproduction Log

## Claim under test

One Review Delivery can receive one immutable human-confirmed Completed Fix with complete source
lineage, while product-owned lifecycle context describes evidence and retained authority without
granting GitHub access or merge authority.

## Stress runner correction

The canonical Stress invocation intermittently terminated before migrations with Node reporting
an uncaught `undefined`. Reproduction established two linked Windows runner defects:

1. `embedded-postgres` rejects without an error object when its child exits before readiness,
   while the runner discarded startup diagnostics.
2. Its Windows stop path launches `taskkill /t` asynchronously and can return when the main
   process exits but before inherited worker processes are gone. Integration or Workflow could
   therefore leave an orphan just as Stress started.

The runner now preserves startup diagnostics and always raises an actionable `Error`. Its shared
shutdown helper invokes `taskkill` synchronously for the exact test-cluster PID, waits for main
process exit, and removes only the non-persistent project database directory. Non-Windows systems
retain the package's native stop path. Five previously orphaned workspace test workers, plus one
created during diagnosis, were explicitly identified by their SignalDesk binary path and absent
parents and then terminated; no user database service or data file was removed.

The entire Foundation-through-Stress ladder was rerun on the exact corrected tree. Integration,
Workflow, and Stress each left zero SignalDesk embedded PostgreSQL processes, and Stress passed
all 17 checks without retry or fallback.
