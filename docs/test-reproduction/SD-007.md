# SD-007 Hosted Review Gate Verification Plan

## Claim under test

A real SignalDesk pull request runs the exact product-owned ordered ladder, and an active GitHub
rule prevents protected delivery when the exact hosted check is absent or failing. This proves a
hosted review gate, not application deployment or canonical L2.

## Exact local and hosted order

1. `npm run test:foundation`
2. `npm run test:component`
3. `npm run test:integration`
4. `npm run test:workflow`
5. `npm run test:stress`
6. `npm run build`
7. `npm audit --audit-level=high`
8. `.\elder.ps1 validate`

Stop at the first failed level. Identify and correct only its root cause, then rerun that same
level before advancing.

## First hosted failure and correction

Private run `32288199733`, job `96182652716`, passed setup, install, Foundation, and Component,
then failed before Integration tests because PostgreSQL `initdb` received `Permission denied`
while changing permissions beneath GitHub's checked-out `D:/a/...` workspace. Later stages were
correctly skipped.

The hosted translation now sets one explicit absolute `SIGNALDESK_TEST_RUNTIME_ROOT` beneath
`${{ runner.temp }}`. Local execution retains `.elder/runtime`. Integration, Workflow, and Stress
all resolve their PostgreSQL directories through that same function, and cleanup remains bounded
to generated children of the resolved runtime root.

Windows cleanup also accepts a nonzero best-effort `taskkill` lookup only after the tracked child
has already emitted `exit`. A missing child exit or a remaining filesystem lock still fails
explicitly within the configured bounds.

The Workflow runner gives the full cold-start desktop transaction a 60-second bound and retains
zero retries. This covers hosted Next.js cold compilation without converting deterministic
product failures into green retries.
