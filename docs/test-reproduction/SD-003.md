# SD-003 Test Reproduction

## Preconditions

- Windows 11 and PowerShell
- Node.js 22 or later
- repository root `D:\Balcony\Template\signal-desk`
- Google Chrome installed for Workflow tests
- dependencies installed from the exact lockfile

Integration, Workflow, and Stress use project-scoped ephemeral PostgreSQL under the ignored
`.elder/runtime/` directory when `TEST_DATABASE_URL` is not supplied.

## Ordered commands

Run one command at a time. Stop at the first failure, fix its root cause, and rerun that same
level before proceeding.

```powershell
npm run test:foundation
npm run test:component
npm run test:integration
npm run test:workflow
npm run test:stress
npm run build
npm audit --audit-level=high
.\elder.ps1 validate
git diff --check
```

## Stress diagnostic note

If Node terminates before migrations or assertions with only a top-level `undefined`, rerun the
same script once with diagnostic tracing:

```powershell
node --trace-uncaught scripts/run-stress.mjs
```

This run observed one such transient termination. The traced command passed all 13 checks, and
the normal `npm run test:stress` rerun also passed all 13 checks without code changes.
