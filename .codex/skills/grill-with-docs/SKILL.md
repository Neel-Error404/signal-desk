# Grill With Docs

Ground challenge in current repository truth.

## Workflow

1. Read `AGENTS.md`.
2. Read the relevant constitution, profile, architecture, ADR, and readiness evidence.
3. Resolve conflicts using executable behavior first, machine contracts second, and plans last.
4. State allowed claims, forbidden claims, approval boundary, and next proof gate.
5. Ask only questions that materially change the plan.
6. Produce a linear implementation or investigation path.

Never treat stale documentation or historical memory as current runtime truth.
