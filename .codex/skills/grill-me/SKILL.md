# Grill Me

Challenge only the assumptions that can change architecture, scope, risk, sequencing, or proof.

## Workflow

1. Restate the intended outcome.
2. Separate facts, assumptions, decisions, risks, and unknowns.
3. Ask three to seven high-leverage questions.
4. Identify the smallest implementation that can teach the truth.
5. Define the claim that successful evidence will permit.
6. Define the claims that remain forbidden.
7. Stop questioning when the next governed action is clear.

Do not ask for information that can be discovered safely from the repository.
