# Architecture Governance

## Workflow

1. Read the project profile, ontology, invariants, and accepted ADRs.
2. Identify bounded contexts, components, contracts, nodes, edges, and side effects.
3. Distinguish deterministic controls from probabilistic decisions.
4. State dependency direction and forbidden dependencies.
5. Assign ownership and change classes.
6. Define executable fitness functions and evidence.
7. Record hard-to-reverse decisions in an ADR.

Keep `ARCHITECTURE.md` concise. Generate diagrams from machine-readable dependency truth.
