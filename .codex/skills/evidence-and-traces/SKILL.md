# Evidence And Traces

## Workflow

1. State the exact claim being evaluated.
2. Link the outcome, work item, change class, agent run, diff, test, artifact, deployment, and result.
3. Record commands, tools, context sources, cost, approvals, and limitations.
4. Redact credentials and sensitive data.
5. Separate product runtime traces from factory execution traces.
6. Mark the verdict as pass, partial, fail, or blocked.
7. Preserve limitations so evidence cannot support a broader claim than it proves.

Configuration and documents are not evidence that a capability ran successfully.
